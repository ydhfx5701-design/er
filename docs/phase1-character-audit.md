# PHASE 1 캐릭터 감사 및 전수 테스트

## 수정 전 분류

### DONE

- `CHARACTER_IDS`에 36개 직업 ID가 존재했다.
- QA 화면에 36개 직업을 한 번에 스폰하는 진입 버튼이 존재했다.
- 실행 중인 작은 캐릭터 렌더러에는 캐릭터 아래 이름과 타원형 그림자가 없었다.

### BROKEN

- 첨부 픽셀 캐릭터를 쓰지 않고 코드로 그린 임시 몸통·발·모자를 사용했다.
- 발이 공통 소켓이 아니라 화면 좌표에 직접 그려졌다.
- 방향 전환이 `CharacterRoot` 전체 반전이 아니어서 몸·발·손·장비를 하나의 리그로 보장하지 못했다.
- 기존 `VillagerMode`가 이동·생활·전투 의미를 섞어 사용해 한 캐릭터에서 이동/공격 모션을 엄격히 배타 처리하는 상태머신이 없었다.
- 36개 전수 화면이 직업마다 서로 다른 한 상태만 보여줘 좌·우 걷기와 필수 상태를 전수 검사하지 못했다.

### MISSING

- 36개 직업의 `body.png`, `left-foot.png`, `right-foot.png` 투명 에셋 108개.
- 공통 `BodyRoot`, `leftFootSocket`, `rightFootSocket`, 좌우 손 소켓.
- `IDLE`, `WALK`, `WORK`, `CARRY`, `ATTACK`, `AIM`, `DEFEND`, `EAT`, `DRINK`, `TALK`, `SLEEP` 단일 상태머신.
- 36개 직업 × 상태 전환용 실제 화면 QA 패널.
- 모든 PNG의 알파 경계와 파일 존재 여부 자동 검사.

## 수정 후 검증 기준

- 36개 직업 리그와 108개 분리 에셋을 모두 로드한다.
- 모든 에셋은 투명 알파를 가지며 이미지 테두리에 불투명 픽셀이 닿지 않는다.
- 정지/작업/운반/공격/조준/방어/식사/음주/대화/수면 중 발 이동 수는 0이다.
- `WALK_LEFT`, `WALK_RIGHT`에서만 36명의 발이 교대로 움직인다.
- 오른쪽 방향은 몸, 양발, 손, 장비가 포함된 `CharacterRoot` 전체를 한 번에 반전한다.
- `ATTACK`은 전투 가능 직업, `AIM`은 원거리 직업, `DEFEND`는 방패 역할 직업에만 적용한다.
- 캐릭터 전체 실루엣과 양발이 잘림 없이 보이며 캐릭터 아래 이름/그림자는 그리지 않는다.
