# PHASE 2 — 맵 / 건물 / 사이드뷰 전수 검수

검수 기준 화면: 1280×720, 프로덕션 빌드 서버

## 작업 전 분류

- DONE: PHASE 1의 36개 직업 공통 CharacterRoot, 몸통/왼발/오른발 리그, 상태머신과 좌우 반전 구조
- BROKEN: 3개의 깊이 행, Y축 카메라 드래그, 깊이 압축 투영, 건물별 제각각인 크기와 저장 좌표, 작은 가로 화면에서 고정 720px QA 높이
- MISSING: 공통 건물 접지 기준, 소형/중형/대형 크기 체계, 완전한 한 줄 이동 경계, PHASE 2 전수 검사 화면, 모바일 가로 드래그 검수

## 수정한 시스템

- 지상 이동 영역의 Y를 `BUILDING_BASELINE` 한 값으로 고정
- 투영과 역투영을 1:1 사이드뷰 좌표로 정리
- 카메라는 X축 드래그만 허용하고 Y축 드래그를 무시
- 마우스 휠/핀치 줌을 0.45–2.00으로 제한
- 건물 하단과 내부 작업 위치를 공통 지면선에 고정
- 건물을 소형/중형/대형/야외 작업장 규격으로 정규화
- 24개 건물의 지붕·외형·내부 핵심 소품과 야외 작업장 표현을 구분
- 건설 미리보기의 겹침/월드 경계/지면선 판정을 유지하고 빨강·초록 상태를 실제 화면에서 검증
- 배경과 지면을 이음새 없는 코드 드로잉 사이드뷰로 정리
- PHASE 2 전수 QA 배지에 건물/주민 접지 수, 이탈 수, 카메라와 줌 값을 노출
- QA 화면도 896×414 가로 화면에서 월드가 보이도록 최소 높이를 정리
