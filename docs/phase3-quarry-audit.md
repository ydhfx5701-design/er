# 와글타운 PHASE 3 — 돌산 채굴 시스템 검수 기록

## 작업 전 분류

### DONE

- PHASE 1 공통 캐릭터 리그와 지면 접지 기준
- PHASE 2 완전한 사이드뷰, 한 줄 건물 배치, 좌우 카메라
- 지상 돌산·임시 적재장·저장소의 기초 위치
- 곡괭이 타격 시에만 재생되는 거리 감쇠 채굴 음원

### BROKEN

- 작업 슬롯은 5개였지만 실제 좌표가 2곳만 반복되어 광부가 겹쳤음
- 낙석이 돌산 표면이 아니라 지면까지 떨어졌음
- 낙석이 곡괭이 타격음 슬롯을 재사용했음
- 돌산이 작은 돌의 집합보다 하나의 매끈한 덩어리처럼 보였음
- QA가 요구된 광부 3명 대신 5명을 생성했음
- 채굴·적재·수거·저장 단계를 개별 계측할 수 없었음

### MISSING

- 서로 겹치지 않는 외벽 작업 슬롯 4개
- 돌산 표면 높이 계산과 표면 충돌 낙석
- 쌓인 돌 조각의 지속적인 시각 표현
- 5개 채굴 음향 연결 슬롯
- 채굴·희귀 확률·운반·재생·저장 용량 데이터
- PHASE 3 전용 3광부·2운반꾼 자동 검수 패널

## 변경 내용

- 지하 광산, 사다리, 포털, 지하 내비게이션 레이어와 사용하지 않던 지하 이미지 슬롯을 제거했다.
- 돌산을 13단의 작은 픽셀 돌 조각으로 다시 구성하고 철·구리·수정·희귀 광맥을 소규모 군집으로 배치했다.
- 낙석마다 실제 돌산 표면의 `landingHeight`를 계산한다. 충돌 시 돌산 잔량과 상단의 쌓인 돌 조각이 증가한다.
- 최대 잔량 100에서 낙석 보충이 멈추고, 잔량이 높을수록 낙석 간격이 느려지게 했다.
- 광부 4명이 서로 다른 외벽 슬롯을 사용할 수 있으며, 추가 광부는 안전 대기 구역에서 기다린다.
- 광부는 외벽 슬롯에 정지한 상태에서만 곡괭이 타격과 채굴을 수행한다.
- 광부가 광물을 임시 적재장에 내려놓고, 운반꾼이 수거해 저장소에 넣은 뒤에만 최종 자원이 증가한다.
- 초기 채굴 분포는 일반 돌·철·구리·수정·고대 광물로 정리했다.
- `stone_fall`, `mining_hit`, `ore_pickup`, `carry_drop`, `storage_deposit` 연결 슬롯을 분리했다. 현재 제공된 MP3는 `mining_hit`에만 연결했다.
- 업그레이드 데이터는 `miningSpeed`, `rareFind`, `carrySpeed`, `carryCapacity`, `regenSpeed`, `storageCapacity`로 분리했다.
- 저장 용량을 실제 입고 제한에 적용하고 HUD에 현재 저장량/최대 저장량을 표시했다.
- 이전 저장 데이터는 새 배열·통계·음향 슬롯을 안전하게 보완하도록 마이그레이션한다.
